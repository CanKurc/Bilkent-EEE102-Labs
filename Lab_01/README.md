# Lab 1: Introduction to Oscilloscopes and Signal Generators

## 📝 Overview
This folder contains the laboratory report and official assignment documentation for the first experiment of EEE 102. The primary focus of this lab was familiarization with essential laboratory equipment, specifically oscilloscopes and signal generators, and understanding how to properly measure and analyze waveforms.

## 📂 Files in this Directory
* `lab1_assignment.pdf`: The official lab assignment instructions provided for the course.
* `EE_Lab_1_CanKurc.pdf`: My complete lab report detailing the measurements, methodology, and conclusions derived from the experiment.

## ⚙️ Key Concepts Covered
* Operation and calibration of oscilloscopes.
* Usage of signal generators to create specific waveforms.
* Measuring amplitude, frequency, and time periods of electrical signals.
