# Lab 3: Combinational Logic Circuit on Breadboard

## 📝 Overview
This folder contains the documentation for the third experiment of EEE 102. This experiment focused on practical hardware implementation, specifically designing, building, and verifying a logic circuit on a breadboard using discrete TTL ICs, entirely independent of an FPGA. 

## 📂 Files in this Directory
* `lab3_assignment.pdf`: The official lab assignment detailing the circuit requirements and logic functions.
* `EE_Lab_3_CanKurc.pdf`: My complete lab report, detailing the hardware construction, truth table verification, oscilloscope readings, and hardware troubleshooting steps.

## ⚙️ Key Concepts Covered
* Physical hardware implementation using discrete logic chips (74HC08 AND, 74HC32 OR).
* Integration and configuration of a 74HC163 4-bit binary counter driven by a signal generator.
* Hands-on hardware troubleshooting (e.g., addressing floating pins, logic signal offsets, and component orientation).
* Signal verification using an oscilloscope and the construction of a visual LED monitor board.
