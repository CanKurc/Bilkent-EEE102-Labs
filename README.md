# EEE 102: Digital Design Lab Repository

This repository contains my weekly lab assignments, VHDL source code, and comprehensive lab reports for the **EEE 102** course at Bilkent University.

## 🎯 Repository Purpose
The purpose of this repository is to document my progression in digital logic design, from fundamental gate-level implementations to more complex sequential circuits. All hardware designs are targeted for the **Basys 3 FPGA** board.

## 🛠️ Tools & Technologies
* **Hardware Description Language:** VHDL
* **Development Environment:** Xilinx Vivado
* **Target Hardware:** Digilent Basys 3 Artix-7 FPGA

## 📂 Directory Structure
Each lab folder typically contains:
* `src/`: VHDL design modules (`.vhd`).
* `sim/`: Testbenches used for behavioral simulation (`.vhd`).
* `constraints/`: The `.xdc` files mapping the design to the physical pins on the Basys 3 board.
* `Report.pdf`: The detailed lab report containing circuit schematics, simulation waveforms, and implementation results.
